Proyecto: Code4Boxing

Descripción:
Sistema web para gestión de clientes en gimnasios de boxeo. Actualmente funcional en entorno local, en transición a SaaS multi-cliente.

Funcionalidades actuales:
- CRUD de clientes
- Generación de contratos en PDF (reportlab)
- Exportación de datos (CSV)
- Autenticación (login/logout)
- Recuperación de contraseña
- Dashboard con métricas
- UI tipo aplicación (layout persistente con base.html)

Stack tecnológico:
- Backend: Django
- DB: SQLite (dev) → futura migración a PostgreSQL
- Frontend: HTML + CSS puro
- Librerías: reportlab, csv
- Deploy: Render (en progreso)

Arquitectura actual:
- App principal: clientes
- Templates: clientes/templates/clientes/
- Static: clientes/static/clientes/
- Layout base: base.html
- Protección de vistas: login_required

Estado actual:
Sistema funcional pero con áreas de mejora en:
- Arquitectura (modularidad, separación de responsabilidades)
- UX/UI (flujo, consistencia, experiencia tipo app real)
- Performance (tiempos de respuesta, carga)
- Escalabilidad (multi-tenant, crecimiento a múltiples gimnasios)

Objetivo:
Evolucionar a SaaS multi-cliente, mantenible, escalable y con buena UX.

Forma de respuesta esperada:

- Enfocada en implementación
- Con ejemplos de código cuando aplique
- Sin teoría innecesaria
